# GPU extras for object_detection on NVIDIA hosts (Ada, desktop CUDA).
# Installs onnxruntime-gpu plus NVIDIA pip wheels for CUDA runtime + cuDNN 9
# (required for CUDAExecutionProvider). TensorRT EP still needs system TensorRT.
#
#   pip uninstall -y onnxruntime  # avoid CPU+GPU wheel clash
#   pip install -r requirements-detection-gpu.txt
#
# Then verify:
#   python -c "import onnxruntime as ort; ort.preload_dlls(); print(ort.get_available_providers())"
#
